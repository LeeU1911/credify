FAQ

    
Is it legal to run on my employer's repos?
      
Credify never reads code into anything it shares. It only counts things locally. Still, check your employment agreement, and you choose exactly which repos to include.

    
Can't people fake the numbers?
      
Local stats alone can be faked, which is why we treat them as your personal insight. Credibility comes from peer and CI signatures, which arrive in phase 2.

    
Can my coding agent install it for me?
      
Your agent can read llms.txt and prepare the command. You run it yourself. We don't want tools that install telemetry without a human.

    
What does it cost?
      
Free for engineers. Companies will pay later to find and verify talent.
